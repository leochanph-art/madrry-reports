Set up the quote proxy (free, ~5 min)
  1. Sign in at dash.cloudflare.com (free plan is fine) → Workers & Pages → Create application → Create Worker.
  2. Name it (e.g. madrry-quotes) and Deploy the default stub.
  3. Click Edit code, replace everything with the contents of cloudflare_quote_worker.js from the workspace repo, then Deploy.
  4. Copy the worker URL, e.g. https://madrry-quotes.<you>.workers.dev.
  5. Paste that URL into this page’s ⚙ Settings → Quote proxy URL → Save. The page switches to FULL mode (batched quotes + volume alerts).
  6. Optional: also write the URL into live_price_proxy.txt in the workspace root, so the daily export bakes it into monitor_data.json as the default for every device.
